# 《林间奇物铺》美术规范 v0.2 · 3D

2026-10-22 用户明确要求项目改为 3D，其他设定不变。当前是 3D 样片制作与验证阶段，尚未取得独立通过结论。历史 2D 图集和评审保留作溯源，不能作为本版完成证据。

## 方向与空间

保留温暖、治愈、森林动物和生活魔法的绘本气质，以有体积的造型、柔和漫反射、圆润边缘和低反差阴影表达。主色为蜂蜜木、奶油、苔绿；微光点缀浅蓝和暖黄。场景与角色使用实际网格。

固定树屋剖面：上层店面，中层工坊，前方庭院；地板、梁柱、后墙、圆窗、屋檐与植被具有厚度。侧屋修复改变模型、窗户和陈设。正交镜头提供全景、庭院、工坊、店面四个观察位置，属于可逆可视化实现选择，不添加自由建造、自由走动或新经营机制。

点按 3D 对象打开原有配置面板，同时提供中文入口和状态；镜头和角色动画均不得影响经济结算。

## 模型、材质与图标

- ForestGeometry.cs：圆润网格、旋转体、管线、圆环、材质缓存和静态合批。
- ForestModels.cs：四种作物、六种商品、设备、货架、五位熟客及职业配件。
- ForestWorld3D.cs：树屋、庭院、侧屋、装饰、灯光、镜头、射线选择和状态绑定。
- Assets/Resources/ForestMatte.shader：哑光色彩、轻微表面变化、实时受光与阴影。
- 图鉴、对话和配方面板缩略图由相同 3D 模型在本地独立摄影棚渲染并缓存。
- 几何构造是制作方式，不能作为美术通过依据。轮廓、面部、职业配件、材质、光照与动态仍须独立运行评审；明显临时几何按工作流判为阻断。

猫头鹰以圆框眼镜、围巾、旧书辨识；刺猬以背刺、围裙、雏菊辨识；松鼠以大尾、马甲、橡果挎包辨识；兔子以长耳、邮差帽、蓝制服、信包辨识；小熊以厨帽、围裙、面包辨识。共享圆润比例、深色眼睛及细小高光。

## 手机界面

保留参考宽 1080、竖屏、安全区域、顶部资源和目标、底部小店/委托/图鉴。面板保留配方、库存、计时、锁定条件和升级费用。缺货、满仓、缺料和预留均有中文提示。

主界面实时渲染原生 3D 场景，通过显示窗口支持射线选择。文字、对象点击范围、滚动与长屏取景须重新进行安卓验证；最终证据来自 APK 实际屏幕。

## 动态与性能

作物按真实进度生长；设备表现工作状态；顾客购物反馈由销售事件触发，动画不驱动结算。音乐/音效独立开关，简化动画不改变收入。网格、材质复用和静态合批用于安卓优化，实际性能仍须测量。
