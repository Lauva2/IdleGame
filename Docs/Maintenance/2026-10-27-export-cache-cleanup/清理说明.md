# Android生成导出缓存清理

正式life02取证期间E盘余量降至522,633,216字节，依用户清理无用文件的既有授权，执行`Tools/Prune-UnityBuildCache.ps1 -CacheGroup AndroidExport`。

仅删除`E:/UnityProject/IdleGame/Library/Bee/Android/Prj`中349个生成文件，共292,832,936字节；这是Unity自动导出的Gradle/IL2CPP暂存项目，不是主项目源码。Unity/bee构建进程均已停止，绝对路径及所有祖先均位于指定项目，无重解析点、无Git跟踪文件；实际清理用PowerShell原生`Remove-Item -LiteralPath`。清理后E盘余量816,181,248字节，期间设备取证会继续使用空间。

清理前后实际校验正式APK、225输入清单与源码ZIP SHA均不变，详见`plan.json`和`result.json`。Assets/Packages/ProjectSettings、普通/准备存档、全部原片、必要原图、历史评审/索引、交付APK和源码归档继续保留；`Library/Bee/artifacts/objcopy_*`的原生调试符号未删除。

下一次Unity构建会重新生成这些缓存。此操作不改变APK内容、场景像素或经济/存档规则，不产生新的候选或沿用未完成美术评分。
