## 1. ART3D02-001 的草稿改善判断

**有实质改善，但不能凭此关闭原问题。**

`05-region-0.png` 中，主树从分离的扁椭圆块层叠，变成具有连续大轮廓的树冠；中央隆起与左右延伸可以读成同一棵树。树干弯曲、根部和分枝连接也比 d06 的粗直 Y 形更连贯。右侧小树的干体随之改善。原来最明显的“几个基础体拼成树”的观感减弱，这一变化直接回应了原问题，并非仅仅因为改成了非球体而认可。

制作方已知的主干尖端少量穿出树冠，在本图仍可见；本报告不假设下一次修正已经生效。

**除该尖端外，最优先的残留是冠面细节与叶片的统一性。** 主树冠正面仍有密集凹凸、暗沟和软团状起伏，中央及下缘较明显；前表面的少量浅绿、深绿橡叶像零散贴在大体积外侧，各簇与冠面大形之间的关系偏弱。主冠占全景很大面积，这种粗糙软团体积与家具、人物较干净的表面处理差异醒目。问题重点已从“分离几何块拼装”转向“连续冠体是否完成了有意图的叶团与表面组织”。

后续画面应让大轮廓、明暗起伏与叶片细节读成统一的树冠，避免零散叶片附在一整块绿色体积上的感觉；不能仅修掉尖端后就认定 ART3D02-001 整项通过。这里描述的是视觉目标，不指定制作方法。

## 2. 左后帘门路线

**已查看帧内，路线方向有改善。**

猫头鹰 `0020～0024`、刺猬 `0080～0085` 均回到左后帘门附近离开；没有在这些片段中重现 d06 从右柱外走出地板的问题。抽帧中保持单顾客，没有发现两位顾客重叠。柜台移到左侧后，四座货架与编号仍可见，未发现新遮挡掉整座货架的退化。

需要保留的观察限制：进出门的小区域与柜台、第一货架较拥挤。刺猬 `0028～0029` 出现时位于柜台后侧，初看容易读成柜台工作人员。猫头鹰 `0023`、刺猬 `0083` 仍有明显主体在帘门前，随后采样帧为空；目前抽帧不足以判断实际连续运动是否自然进入帘后。本报告**不把这一采样差异直接定性为瞬移或穿模**。正式录像须能明确看出角色来自帘后、进入店内、回到帘后；同时核对体型更大的熊和松鼠尾巴与柜台、帘门的关系。

本项只是草稿改善记录，尚不正式关闭 ART3D05-002。

## 3. 最关键的另一项可见残留：购买表现不够醒目

证据：猫头鹰 `0015～0017`、刺猬 `0075～0077`。

这两个购买停留阶段都主要朝向后方柜台，玩家看到背部。浅色购物袋确实存在，但在当前店面构图里很小，位于身体左下侧、接近脚边；提拿关系和“刚完成购买”的动作不易一眼辨认。尤其刺猬背部密集尖刺占据角色轮廓，袋子和手势更弱。顶部“店面收入”文字比场景中的购买结果明确得多。

这不是说没有购物袋或没有购买动作，而是它们在实际玩法视角中的信息强度不足。后续应让玩家在原有店面视角、不依赖放大和逐帧寻找时，能够辨认收银停留、完成购买、携物离开三个阶段；还需看五位顾客完整实时录像，才能判断节奏和重复观看效果。

## 4. 故事排版的观察结果

`11c-story-0.png` 中，“谢谢你，店主。”完整处于一行；`11c-story-2.png` 中，“找到了！”和最后一句均无孤立标点换行。原 ART3D06-001 在这两张草稿图中的具体表现已消失，中文行距、文字与底部操作区的距离也清楚。

本次没有查看全部五篇故事和所有画幅，因此只确认上述两张 Windows 样本的改善，不提前关闭其他画幅与安卓复验要求。

## 本轮结论及后续证据

这轮草稿在主树整体连接、左后出入方向、两处已知中文断行上均有可见改善。当前最值得继续处理的画面问题，是主树冠表面与叶片的统一性，以及购买停留时背向柜台、购物袋过小造成的反馈辨识不足。帘门全过程须由连续录像进一步判断，不能把没有抽到问题当作通过。
