**残留一般问题 M02：** 多数鱼仍共享小黑珠眼、小口与同类折线腮标记，头部表情差异比体型/尾形弱；圆叶溪鲫/红鳍林鲤及红鳍林鲤/金线鲤的家族感仍强。当前没有认定重要品种无法辨认，也不要求全部12种在完全去色、去字条件下做到物种学鉴定。后续应在实际APK的缩略图、大图、出水不同朝向复核，尤其检查背鳍根、须根、尾柄在转动时是否露缝；单个正侧视图不足以排除背面连接问题。

## 3. 三钓点与默认构图

逐张看过 `habitat-0/1/2`及`left-habitat-0/1/2`。

- **溪边浅滩**：浅色水中椭圆石滩、露出的石子、细草与芦苇，与单纯河面相比有明确浅水地标。
- **木桥深潭**：桥侧暗水环、岸石与香蒲使其与浅滩有实际区别，不再只有名字和桥两侧方向之差。
- **旧亭洄湾**：亭屋、池塘曲岸、睡莲、水边小台面构成独立环境；右侧树冠覆盖部分水面，当前浮漂与收鱼篮未被遮住。
- 钓鱼上下文中没有“观察/钓鱼”世界牌压在篮筐上；离开后的地图牌和地图镜头按钮恢复可见。钓鱼状态只见面板底部一组镜头按钮，没有在画面内再出现一组地图镜头按钮。
- 提示面板高度变紧凑，当前离屏默认画面能同时看见竿、线、平台、篮筐与水面，三饵和鱼谱入口仍在。但这不是对Android窄屏/缺口的实际结论。

**M01，需复核的明确状态问题：** `habitat-1.png`标题为“自动等待鱼讯”，红白浮漂约在原图(x525,y800)，视觉上处于平台上方，尚未落到平台前的深潭水面。将此单帧提交主代理核对后，主代理说明：该图在ShowFishing后立刻拍摄，前0.42秒仍为抛竿轨迹，稳定等待的连接断言在稍后Advance(0.6)才执行；这张不是稳定等待证据。该说明解释时点，但不能抹去当前图中文与姿态不一致。主代理拟在R03将首段文字改为“抛竿入水”，并另存三处0.6秒稳定等待。**目前仅收到修改计划，未查看R03，不记为已修复。**

此处未直接认定“深潭浮漂长期悬空”或Android运行故障。复验要看到抛竿→真正落水→稳定等待的分别对应状态；三个钓点的稳定端点都应在水面，实际连续录像中不能跳过中段。

**残留一般问题 M04：** 深潭暗水区的外沿较硬、近似叠加圆盘，与河面之间的过渡仍机械；旧亭大屋顶和右树冠占据较多世界窗口。当前地标已有效区分，不能因这些质感问题称三钓点仍完全一样；实际相机缩放/平移后再判断遮挡严重程度。

## 4. 静态阶段姿态与五类提示

已看 `motion-01-bite/02-reeling/04-out-of-water/05-into-basket/06-next-cast`、五种notice及`reduced-landing`。

- 01/02有水面波纹、浮漂下沉与“浮漂下沉·自动收竿”状态；04能看到鱼在水面上方、白线沿竿尖到鱼头附近；05鱼落在篮中；06回到下一竿，旧回执仍显示上次真实钓获的第1尾。
- 这些是明确准备的进度姿态，不能证明两个时点之间的轨迹平滑、鱼嘴始终连接或入篮时不穿边。尤其04鱼体较小、侧倾，不能把检查脚本“Line stays...”升级成独立全程无缝结论。
- 减少动画图保留篮中鱼、正常回执与竿，所见静态不矛盾；是否真的减少晃动必须看实际片。
- “新发现”“长度新纪录”“重量新纪录”“长度与重量新纪录”均为深绿条/浅字，文字本身区分事件；普通图文件名虽为“自动钓获”，画面文字实际是“最近钓获”。这不是错误品种，也不按文件名认定文字缺失。
- 第1/2尾序与鱼名/大小/钓点/饵料放在同一回执卡，五类最长文字未越界，图标没有挡住品名、品质和三饵。通知的首次/破纪录判定正确性、无重复发放仍需实际同包功能记录；准备基线允许产生相同参数的不同测试提示，不能据相同22.1厘米/120克指控自然随机造假。

**残留一般问题 M05：** 五张notice中的水花/亮团接近乳白球体，明显大于浮漂，静态时会掩住出水位置的一部分，水花质感较重。未见长时间遮挡证据，不先升级为阻断。后续实际动态应检查持续时间、鱼体首次显现、线嘴关系及减少动画模式，不能仅靠挑选鱼已经入篮后的帧证明出水可读。
