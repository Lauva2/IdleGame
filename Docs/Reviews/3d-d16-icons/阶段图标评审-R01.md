## 阶段结论

图标化方向在所看画面中成立：暖黄、奶油白、深绿与现有界面及木质森林场景协调；图形轮廓简洁，导航和教学保留短中文，减少了大段常驻说明。当前主界面未见关键中文截断、按钮相互覆盖或替换图标后出现缺图。d15 已修的孤立句号与词语末行问题未在本批教学卡重新出现。

但“减少文字”仍须保留准确的经营含义。最明确的待改意见是章末摘要将累计销售替换为普通金币图标后，与钱包余额产生歧义。小尺寸资源图标区分、纯图标状态首次学习及帮助入口发现性也仍有一般打磨空间。不能因为图形互不相同就认定玩家无需说明即可理解。

## 分项观察

### 图标风格与小尺寸

18 中设置齿轮、庭院幼苗、工坊坩埚、店面门脸、委托信封、图鉴书、仓库箱、锁、方向和关闭等，具有可辨的外轮廓。深绿底上的浅色版本清楚；按钮选中与未选中不仅文字颜色不同，底色和图标配色也随之变化，02/03/05/08 中选中的栏目可辨。

64px 样张能读出大多数内部细节；32px 下锁、齿轮、箱、书等轮廓仍明确，金币的环内细线、声望的叶片/斜茎，以及部分花朵、货架小格细节更容易缩成小色块。尤其金币、声望都以圆形金边为外轮廓，差异较依赖内部形状，见 ICON16-002。当前 HUD 的两枚资源图标仍有位置与形状差别，没有证据支持将它们判为完全无法辨认；也没有实际小屏阅读数据可直接认定终端舒适度通过。

平面图标与场景 3D 缩略图属于不同表现层，但共用暖色与绿调，当前没有明显外来风格冲突。12 四种作物缩略图形体、颜色不同且保留中文名称，没有只靠颜色区分原料。

## 问题与建议

### ICON16-001：累计销售与持有金币的摘要含义混淆

级别：一般信息表达问题，建议正式候选前明确修正。证据：12、17 的章末摘要，对照 d15 原“累计销售 0/60,000”。

当前用普通金币图标加“0/60,000”替代累计销售文字。相同金币图标也用于顶部钱包和扩建费用，因此摘要很容易被理解为要求持有 60,000 金币；实际门槛是累计销售，两者会影响玩家如何理解是否应消费。仅凭金币形状不能表达“累计销售额”。

建议在该摘要保留“累计销售”或“销售额”短标签，或采用具有明确销售含义的图形并保留首次解释，不必恢复大段说明。15 当前可见部分没有覆盖销售条件，不能据此认定全文中没有解释；即使详情有解释，也不消除主摘要本身的歧义。

复验：章末摘要能直接区分钱包余额与销售累计，且数字语义正确；对应实际详情条件完整可读。该问题是当前可见语义歧义，不是本轮已确认的经济数值错误。

### ICON16-002：32px 资源图标的辨识余量较小

级别：一般小尺寸精修。证据：18 的金币/声望 32px 样张及实际顶部 HUD。

两者共同的金色圆环比内部特征更醒目，细线和小叶片缩小时易弱化。建议加强声望的独特轮廓或简化内部细节，保持小尺寸也能靠形状认出；不只靠绿色与金色差异。需在实际长/窄屏和正常观看比例复查，不能以放大样张替代阅读验证。当前不判为资源完全不可识别。

### ICON16-003：纯状态图标的首次学习与帮助发现性待验证

级别：一般引导关注。证据：05/07/19/20 及页尾入口。

齿轮“待配置”、勾选标签“预留”、金币“营业”需要记忆约定。经营说明图例能补足语义，但在部分初始教学图中页尾说明按钮只露出一部分，不能据静态图确定新玩家会发现。建议首次出现时就近提供短状态名或可发现的解释方式，或在真实新档测试中确认现有提示足够；无需把所有长句重新放回常驻界面。

复验应观察首次配置、缺货、委托预留与解除后的真实连续变化，以及实际手指到达图例的过程。图标不同、handler PASS 和静态图例存在均不能单独证明理解和操作已通过。
