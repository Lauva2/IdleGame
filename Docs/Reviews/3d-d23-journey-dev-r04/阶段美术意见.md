后续复验特别需要：

1. 真实在线收获/坩埚/工作台/售卖各一次以上，HUD短汇总与世界反馈对齐；并发量下不过大、不串来源、不盖编号、控件或鱼篮。

3. 后台恢复/离线报告、切准备状态后不重播历史“刚刚”；所看摘要值来自当前前台事件。
4. 缺料/满仓/预留三负例无虚假完成；减少动画仍有可读回执；实际平移使售货来源画外时不凭空出现屏内金币。
5. 庭院多处/双设备/销售同时运行时，比例和动效噪声仍可控。不可只挑选清闲单个回执视图。
