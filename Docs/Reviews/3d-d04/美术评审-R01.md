## 3. ART3D02-001～008 复验结果

### ART3D02-001：主体和环境仍有明显初步几何拼装观感

状态：**部分修复，未关闭**  
当前严重性：**美术阻断**

已修复：

- 未开放货架已有可辨的货架边缘、封布、封绳和锁扣，不再是无语义奶油长方体。
- 高反差棋盘屋顶已改为近色错缝瓦片。

仍存在：

- 主树冠依然由大量边界清楚、相似尺度的椭球团堆叠；增加的小叶凸起没有改变主体轮廓的重复感。
- 主干和分叉仍以粗大的几何段连接，表面几条竖线未形成足够的形体与材质层次。
- 主场景由大面积均一底色包围，底盘边缘重复灌木较明显，整体仍偏模型陈列样片。

证据：Windows 与 Android 的 `05-region-0.png`、`16-annex-before.png`、`16b-annex-after.png`，动态 `0000`。

该结论针对主视觉中实际可见的初步拼装效果，不针对程序生成方式，也不要求写实树木或增加面数。

整改及复验：先完成一棵与树屋统一的正式主树，处理树冠整体轮廓、大小层次、枝干走向及连接收束；环境增加有目的的空间层次。全景实际手机尺度下不再首先读成重复球体和几何分叉集合，再复查近景与纪念图。

严重性：**一般**

Android 庭院台阶、种植框、工坊梁柱、地板及角色周边的投影比 Windows 更硬，近景中边缘阶梯明显，削弱了既定柔和绘本表现。

### ART3D04-002：生产通知覆盖经营信息，来源不够明确

严重性：**一般**

“加工完成”“自动收获 +N”和收入通知可能同时出现；部分通知覆盖状态卡、操作说明或章节进度。“加工完成”也未指明设备或商品，在庭院中出现时难以对应来源。

证据：Android 动态 `0020、0025、0030、0040、0050、0060、0070、0080`；Windows 动态 `0030、0070、0114`。

复验：满负荷生产时通知层次清楚，不遮挡关键状态和操作；可识别来源，连续事件不会产生难读堆叠。现有证据不足以认定持续遮挡关键按钮，因此本轮不列为阻断。

仍不能确认：

已知短 ADB tap 偶有未响应，600 ms 同点 swipe 可响应；原因未证实。截图只能证明部分状态最终变化，不能据此判定触控全部通过，也不能把问题归因于游戏或 ADB 中的某一方。

下一轮需要实际输入关联的连续录屏，或足够密集、带操作时间记录的原始帧序列。动态至少覆盖顾客移动与购物、模型点击、收获、两设备、销售、滚动和面板切换。不要只延长静态等待时间。

功能、正常第一章流程、存档、离线和稳定性验收不属于本报告的通过范围，不能由美术截图替代。
