# IdleGame — 林间奇物铺

安卓竖屏、单机离线的 3D 治愈放置经营游戏。玩家经营森林中的树洞魔法小店，通过种植原料、加工商品、自动销售和居民委托，逐步修复并扩建店铺。

当前进行 **d14建筑扩容**：在d13森林小院与十二田基础上，店铺/工坊实际木地板面积扩大至原约2.2倍，人物和家具保持比例，扩大走道并重排设施、入口和顾客路线，保留原经营范围与第一章门槛。本轮完成必要Unity编译、实际3D开发预览及12田/7设施射线检查；没有构建新APK。音乐保留，正式MuMu、长时、声音和最终美术验收按用户要求之后进行；旧91.5分不自动适用新布局。Unity启动Logo设置已关闭，实际安卓启动待后续验证。详见[建筑扩容记录](Docs/建筑扩容-2026-10-23.md)、[森林小院记录](Docs/森林小院空间改造-2026-10-23.md)和[交付说明](Docs/交付说明.md)。

## 打开工程

1. 使用 Unity Hub 安装 **Unity 2022.3.62f2**；后续安卓开发需安装对应的 Android Build Support、SDK、NDK 和 OpenJDK 模块。
2. 在 Unity Hub 中添加并打开仓库根目录。
3. 等待 Unity 恢复包依赖并导入资源。

版本控制保留 `Assets`（含 `.meta`）、`Packages` 和 `ProjectSettings`。`Library`、日志、本机设置、IDE 生成文件和构建产物由 `.gitignore` 排除，Unity 会在本地重新生成所需缓存。
